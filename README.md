# FinGuard AI

Enterprise AI-powered Fraud Detection & Investigation Platform.

## Features

- Secure Authentication
- Fraud Detection using Machine Learning
- Transaction Monitoring
- AI Explainability
- Investigation Dashboard
- Alerts & Notifications
- Analytics Dashboard
